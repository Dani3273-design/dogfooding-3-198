# 用户留存转换分析系统

## 项目简介

本项目是一个用户留存转换分析程序，用于分析用户从注册到登陆和消费的行为数据，生成可视化PDF分析报告。

## 功能特性

1. **用户数据分析**
   - 用户ID、注册日期统计
   - 用户登陆记录分析
   - 用户消费记录分析

2. **可视化图表**
   - 每日用户注册数柱状图
   - 7日转换柱状图：用户注册7日内（含第7日）进行首次消费的概率分布
   - 15日转换柱状图：用户注册15日内累积转换率
   - 7日留存柱状图：用户7日内（含第7日）登陆至少一次的概率分布

3. **报告输出**
   - 输出为PDF格式报告
   - 中文报告内容
   - 重复运行自动覆盖原有报告文件

## 使用说明

### 重要说明

**测试数据生成与分析程序是分离的：**
- `generate_test_data.py` - 独立的测试数据生成脚本（仅用于程序测试）
- `main.py` - 纯分析程序，不包含任何数据生成功能

### 步骤一：生成测试数据（可选）

```bash
python generate_test_data.py
```

该命令会自动：
- 随机选择一个月份生成测试数据
- 生成200个用户注册信息
- 生成500个用户登陆记录
- 生成400个消费记录
- 数据文件保存到 data/ 目录

### 步骤二：运行用户留存转换分析

```bash
python main.py
```

读取 data/ 目录下的数据文件进行分析，生成PDF报告到 output/ 目录。

## 测试数据说明

测试数据生成符合真实业务规律：
- 用户注册、登陆、消费多发生在工作日午休时间（12-13点）和晚间（18-22点）
- 周末全天分布相对均匀
- 一个用户可能有0次或多次消费

## 数据格式说明

如需使用真实数据，请按以下格式准备CSV文件：

### 1. registrations.csv（用户注册数据）
```csv
user_id,register_date
USER_0001,2024-03-15 18:30:00
USER_0002,2024-03-16 12:15:00
```

### 2. logins.csv（用户登陆数据）
```csv
user_id,login_time
USER_0001,2024-03-16 19:20:00
USER_0002,2024-03-17 20:10:00
```

### 3. purchases.csv（用户消费数据）
```csv
user_id,purchase_time,amount
USER_0001,2024-03-18 21:00:00,99.90
USER_0003,2024-03-19 12:30:00,199.50
```

## 输出报告说明

PDF报告包含以下内容：

1. **用户留存转换分析概览表**
   - 总用户数、有登陆/消费记录用户数
   - 总体留存率、总体转换率
   - 平均首次登陆天数、平均首次消费天数

2. **每日注册数柱状图**
   - 统计每日新增注册用户数量

3. **7日用户转换率图表**
   - 展示注册后第1-7天内首次消费的用户占比

4. **15日用户累积转换率图表**
   - 展示注册后第1、3、5、7、10、15天的累积转换率

5. **7日用户留存率图表**
   - 展示注册后第1-7天内首次登陆的用户占比

## 技术栈

- **数据处理**: pandas
- **可视化**: matplotlib
- **报告输出**: matplotlib.backends.backend_pdf
- **编码规范**: 蛇形命名法 (snake_case)

## 重要架构说明

- **关注点分离**: 测试数据生成不是分析程序的功能，两者完全分离
- `generate_test_data.py` 是独立的辅助脚本，仅用于测试
- `main.py` 及 `src/` 目录下的代码是纯分析程序，不包含任何测试数据生成逻辑

## 注意事项

- 程序所有运行日志均为英文输出
- 确保系统安装有中文字体以支持PDF中文显示
- 重复运行程序会自动覆盖旧的PDF报告文件
