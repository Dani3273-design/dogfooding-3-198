# 用户留存与转化分析程序

## 项目简介

本项目是一个用户留存与转化分析工具，用于分析用户注册、登录和消费行为数据，生成包含多种统计图表的PDF报告。

**注意**：测试数据生成和分析程序是分开的，测试数据仅用于程序测试。

## 功能特性

1. **每日用户注册数统计**：按日期统计用户注册数量，生成柱状图
2. **7日消费转化率分析**：统计用户注册后7日内进行消费的概率（第1天至第7天）
3. **15日消费转化率分析**：统计用户注册后15日内进行消费的概率（第1天至第15天）
4. **7日登录留存率分析**：统计用户注册后7日内登录至少一次的概率（第1天至第7天）
5. **PDF报告输出**：将所有分析结果整合为中文PDF报告

## 环境要求

- Python 3.9+
- pandas
- numpy
- matplotlib

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 第一步：生成测试数据

运行测试数据生成脚本，生成模拟数据：

```bash
python generate_test_data.py
```

该脚本会生成：
- 200个用户注册信息
- 500条登录记录
- 400条消费记录

### 第二步：运行分析程序

生成测试数据后，运行分析程序：

```bash
python main.py
```

分析程序会：
1. 读取 `data/` 目录下的数据文件
2. 处理数据并计算各项指标
3. 生成PDF报告并保存到 `output/report.pdf`

**注意**：如果数据文件不存在，分析程序会提示先运行测试数据生成脚本。

### 数据文件格式

#### 用户数据 (users.csv)
| 字段 | 说明 |
|------|------|
| user_id | 用户唯一标识 |
| register_date | 注册日期时间 |

#### 登录记录 (logins.csv)
| 字段 | 说明 |
|------|------|
| user_id | 用户唯一标识 |
| login_date | 登录日期时间 |

#### 消费记录 (purchases.csv)
| 字段 | 说明 |
|------|------|
| user_id | 用户唯一标识 |
| purchase_date | 消费日期时间 |

## 测试数据说明

测试数据生成器会自动生成符合真实场景规律的模拟数据：

- **注册时间分布**：偏向周末和晚上休息时间
- **登录时间分布**：偏向午休和晚间休闲时段
- **消费时间分布**：符合工作日休息时间和周末的规律

## 报告内容

生成的PDF报告包含以下内容：

1. **封面页**：报告标题、生成时间、数据概览统计
2. **每日注册统计页**：柱状图展示每日新用户注册数量
3. **7日转化分析页**：柱状图展示注册后1-7天内完成消费的用户比例
4. **15日转化分析页**：柱状图展示注册后1-15天内完成消费的用户比例
5. **7日留存分析页**：柱状图展示注册后1-7天内至少登录一次的用户比例

## 技术说明

- 数据处理：使用pandas进行数据清洗和统计计算
- 可视化：使用matplotlib生成柱状图
- 报告生成：使用matplotlib的PdfPages功能生成PDF
- 编码：所有CSV文件采用UTF-8编码，PDF报告采用中文显示

## 注意事项

1. **测试数据生成和分析是分开的**：`generate_test_data.py` 用于生成测试数据，`main.py` 仅用于分析
2. 程序运行时会自动覆盖已存在的PDF报告文件
3. 确保系统已安装支持中文的字体（如Arial Unicode MS、SimHei等）
4. 测试数据仅用于程序测试，每次运行 `generate_test_data.py` 会重新生成随机数据
