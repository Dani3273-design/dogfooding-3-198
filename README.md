# 用户留存转换分析程序

## 项目简介

本程序用于分析用户留存和转换数据，生成包含可视化图表的PDF分析报告。程序可以统计每日用户注册数、计算7日和15日消费转换率、以及7日登录留存率。

## 功能特性

1. **每日注册统计**：按天统计用户注册数量，生成柱状图
2. **7日转换分析**：计算用户注册后7日内（含第7日）进行首次消费的概率
3. **15日转换分析**：计算用户注册后15日内（含第15日）进行首次消费的概率
4. **7日留存分析**：计算用户注册后7日内（含第7日）登录至少一次的概率
5. **PDF报告输出**：自动生成中文PDF分析报告，支持重复输出覆盖

## 数据格式要求

### 用户注册数据 (user_registration.csv)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| user_id | string | 用户唯一标识 |
| registration_date | datetime | 注册日期时间 |

### 用户登录数据 (user_login.csv)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| user_id | string | 用户唯一标识 |
| login_time | datetime | 登录时间 |

### 用户消费数据 (user_consumption.csv)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| user_id | string | 用户唯一标识 |
| consumption_time | datetime | 消费时间 |
| amount | float | 消费金额 |

## 安装说明

### 环境要求
- Python 3.9+

### 安装依赖
```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 生成测试数据
```bash
python generate_test_data.py
```

测试数据生成参数：
- 用户数量：200人
- 登录记录：500条
- 消费记录：400条
- 数据月份：随机生成一个月的数据

### 2. 运行分析程序
```bash
python main.py
```

### 3. 查看报告
报告将生成在 `output/user_retention_report.pdf`

## 报告内容说明

### 第一页：可视化图表
1. **每日用户注册数柱状图**：展示统计周期内每天的注册用户数量
2. **7日消费转换率柱状图**：展示注册后第1-7天的累计消费转换率
3. **15日消费转换率柱状图**：展示注册后第1-15天的累计消费转换率
4. **7日登录留存率柱状图**：展示注册后第1-7天的登录留存率

### 第二页：数据统计摘要
- 基础数据统计（总用户数、登录数、消费数等）
- 用户行为统计（人均登录次数、人均消费次数等）
- 数据时间范围
- 详细的转换率和留存率数据

## 技术实现

- **数据处理**：使用 pandas 库进行数据清洗和分析
- **可视化**：使用 matplotlib 库生成图表
- **报告生成**：使用 matplotlib 的 PdfPages 生成PDF报告
- **编码规范**：采用蛇形命名规范（snake_case）

## 注意事项

1. 程序运行前需确保 `data/` 目录下存在所需的数据文件
2. 报告输出时会自动覆盖同名文件
3. 程序所有日志输出采用英文
4. 报告内容为中文，已配置中文字体支持
